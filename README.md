# GitHub Contribution Graph Art (Disclosure)

## Purpose
This repository is an educational/demo project that shows how Git commit timestamps affect the GitHub contribution graph.

## Transparency Statement
- The contribution pattern in this repository includes intentionally backdated commits.
- This is done for visual demonstration and learning purposes only.
- This repository does **not** claim that the graph reflects normal day-to-day development activity.

## What Was Done
- Empty commits were created with explicit `GIT_AUTHOR_DATE` and `GIT_COMMITTER_DATE`.
- Commit dates were chosen to reproduce a target contribution-graph dot pattern.
- The process was automated with a JavaScript script.

## What Was *Not* Done
- No attempt was made to impersonate another contributor.
- No hidden history rewrite was used to misrepresent project ownership.
- No deceptive claims are made about productivity or timeline.

## Reproducibility
If you want to reproduce the same educational workflow, scripts and extraction logic are documented in the toolkit used to generate this pattern.

## Important Note
Use this technique responsibly and always disclose when a graph is intentionally shaped for demonstration.
